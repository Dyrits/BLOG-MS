# Agent instructions

- Code conventions no tool enforces live in `documentation/conventions.md`; read it before writing or reviewing code.
- Architecture decisions and their reasons live in `documentation/architecture-decision-record/`; read them before choosing a framework, a library, or how services communicate.
- Verification proofs live in `documentation/verification/`, one dated file per verified change with a sibling folder for its scripts; read the latest before verifying related work, and add a new file rather than editing an old one.
